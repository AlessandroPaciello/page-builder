- (constraint) Tutto il tooling deve restare gratuito — vincolo esplicito dell'utente. Penpot self-host è open source (MPL-2.0) e il server MCP è incluso senza costo aggiuntivo; nessun servizio a pagamento va introdotto.
- (constraint) AD-11 (Architecture Spine): Penpot è single source of truth dei valori di design — la fixture committata da Story 2.1/2.2 non può contenere valori inventati; se il catalogo Penpot reale non è ancora popolato con token/componenti veri, la generazione resta bloccata finché non lo è (nessun placeholder spacciato per dato reale).
- (decision) Decisione utente: estendere lo stack Penpot esistente aggiungendo il servizio penpot-mcp, non crearne uno isolato nel repo page-builder.

- (decision) Conseguenza architetturale: questo spec NON produce un docker-compose dentro il repo page-builder. L'artefatto operativo è l'istruzione/snippet per estendere il compose esterno esistente (fuori dal controllo versione di page-builder) + il contratto stabile (URL/env var) che packages/scripts può assumere.

- (capability) CAP-2: packages/scripts (Story 2.1+) assume un contratto stabile e documentato per raggiungere l'MCP (URL, eventuale variabile d'ambiente per override) senza hardcodare assunzioni fragili.
