# Bootstrap della library Penpot sui contratti

## Description

Una skill crea la library Penpot partendo dai contratti: token semantici (inclusi shadow/ring), un VariantContainer per contratto con gli assi del contratto, token legati su ogni proprietà di stile e plugin data `pagebuilder/contract = nome@versione`.

## Requirements

Verify: L'esito è deciso da uno script di verifica (un container per contratto, assi e valori coincidenti, 0 `variantError`), il bootstrap rifiuta su library esistente e la modalità additiva crea solo ciò che manca.
