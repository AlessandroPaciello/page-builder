# Skill `pds-code`

## Description

La skill `pds-code` porta un componente da Penpot al codice con le voci ET, VC, GC, AC e GA, risponde alle domande del nucleo scrivendo le risposte in Penpot come plugin data solo dopo conferma, e non scrive mai un file `@generated`.

## Requirements

Verify: GC e AC sono verificati su un componente reale, ogni `Finding` domanda mostra le opzioni e persiste la risposta solo dopo conferma, e GA (tsc, test, tema nel CSS, contrasto, axe, un pacchetto font per famiglia) è un gate verde.
